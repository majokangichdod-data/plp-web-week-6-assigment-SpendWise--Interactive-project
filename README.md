# SpendWise Budget Tracker

## Project Description
SpendWise is a simple budget tracker that helps users calculate
their total expenses and remaining budget using JavaScript.

## Project Files
- `index.html` - Provides the webpage structure.
- `style.css` - Styles the webpage and its components.
- `script.js` - Collects user input and performs budget calculations.
- `README.md` - Documents the project.

## Features
- Accepts a user-provided budget.
- Collects three expenses.
- Calculates total expenses.
- Calculates the remaining balance.
- Displays labeled results in the browser console.
- Warns the user when expenses exceed the budget.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Open `index.html` in a web browser.
2. Click the Calculate My Budget button.
3. Enter your budget and three expenses.
4. Open the browser console to see the budget report.

## Learning Outcomes
This project demonstrates variables, data types, user input,
number conversion, reusable functions, calculations, and console output.
